# Format: one line per test: <path under tests/> <outcome> [reason]. The outcome is pass, fail, or skip. A fail or skip
# line needs a reason. The reason starts with its group, followed by a colon; the test summary counts failures by group.

# Pass criterion (see CountMismatchedPixels): each SVG draws into a transparent image of the size of its reference PNG.
# Both images are compared in premultiplied RGBA, 8-bit. A pixel matches when every channel lies within the range of
# that channel over the 3 x 3 neighbourhood in the other image, widened by 24; a pixel that does not match in either
# direction is mismatched. A test passes with at most 40 mismatched pixels.
#
# Calibration (Chromium renders of the whole suite through tests/SvgTools/render-svg.js at the reference size, compared
# with the reference PNGs; tests outside the text category, because text depends on installed fonts):
# - Of the 1146 tests that results.csv records as passed by Chrome, the Chromium render passes 90.8%. The pass rate stops
#   rising at 40 pixels. The rest fail for reasons other than antialiasing: text inside non-text tests, sizing tests,
#   systemLanguage, external files, and behavior that changed since Chrome 123.
# - Of the 132 tests that results.csv records as failed by Chrome, the Chromium render passes 29.5%.
# - Chromium renders that the criterion passes, changed on purpose: a 2 or 4 pixel shift fails 99.8% of them; a red
#   channel change of 32 fails 99.7%, of 24 fails 6.8%. A 1 pixel shift is accepted inside the image.
# - A nearest-neighbour criterion (distance 64, 60 pixels) passes about the same share of Chrome-passed tests (90.3%) but
#   37.1% of Chrome-failed tests, and misses color changes up to 64. The range criterion was chosen for that reason.
#
# Text (phase 3, package T1). The runner loads the fonts of the suite (fonts/) and maps the generic families as the resvg
# test harness does (serif Noto Serif, sans-serif Noto Sans, cursive Yellowtail, fantasy Sedgwick Ave Display,
# monospace Noto Mono). Chromium with the same fonts (render-svg.js --resvg-fonts) passes 59 of the 340 text tests that
# are not undefined behavior. 253 text tests draw a 0.5 wide crosshair line; Skia and tiny-skia place its horizontal
# line 1/8 pixel lower than this renderer, which alone gives about 240 mismatched pixels, so those tests fail with
# reason "text: rasterization" whenever the rest of the image matches. The criterion is unchanged.
